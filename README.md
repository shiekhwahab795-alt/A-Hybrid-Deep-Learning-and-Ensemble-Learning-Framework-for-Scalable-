# A-Hybrid-Deep-Learning-and-Ensemble-Learning-Framework-for-Scalable-
A Hybrid Deep Learning and Ensemble Learning Framework for Scalable DDoS Attack Detection in Internet of Things Networks
This repository contains the implementation of the framework described in our paper: Hybrid CNN–Transformer–Random Forest Framework for Scalable IoT Intrusion Detection Against DDoS Threats

Features
Hybrid CNN + Transformer + Random Forest classifier
Adaptive feature selection
Class imbalance handling with SMOTE, ADASYN, and SMOTE+ADASYN
Evaluation across CIC IoT 2015, 2018, 2023, and CIC IIoT 2025 datasets
Metrics: Accuracy, Precision, Recall, F1, ROC-AUC
